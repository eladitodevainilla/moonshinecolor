# Moonshine Voice Color (VST3 para FL Studio)

Plugin vocal de procesamiento profesional con motor inteligente **RELEARN** para darle cuerpo, color analógico y frescura a tus voces en FL Studio.

## Cómo obtener tu `.vst3` compilado automáticamente en GitHub (sin instalar nada)

1. Crea un repositorio nuevo en [GitHub](https://github.com/new) (por ejemplo `moonshine-voice-color`).
2. Sube todos los archivos de este ZIP a la raíz del repositorio (incluyendo la carpeta `.github/workflows/build.yml`).
3. Ve a la pestaña **Actions** de tu repositorio en GitHub.
4. Espera ~3 minutos a que termine el workflow **Build Moonshine Voice Color VST3**.
5. Haz clic en el workflow completado y descarga el archivo **`Moonshine-Voice-Color-VST3-Windows`**.
6. Copia la carpeta `Moonshine Voice Color.vst3` dentro de:
   `C:\Program Files\Common Files\VST3\`
7. Abre **FL Studio** -> **Options** -> **Manage plugins** -> **Find installed plugins** -> ¡Listo!
